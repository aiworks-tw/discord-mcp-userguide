Discord-MCP 助理使用指引

ChatGPT 多了一個 Discord 幫手,可以幫你整理 Discord 對話、找資訊、草擬回覆。

它只能看到你在 Discord 本來看得到的頻道。不會多、也不會少。

啟動指南

30 秒,一次設定終身用

01

打開 ChatGPT,左側選單進入「應用程式」

在應用程式列表找到 Discord-MCP(紫色 Discord logo,標記「內部」)。

02

點進去,按右上角「開始聊天」

第一次使用會跳到 Discord 登入頁,選你的帳號 → 按 授權。

03

開新對話開始用 —— 寫入時會跳確認框

授權後不會再跳登入。讀取動作直接執行;第一次發訊息會看到下面這個確認框 —— 按 確認 就送出。

讀取功能

不會跳確認,直接執行

你想做直接這樣打
看有哪些可用的 Discord 伺服器用 Discord-MCP 列出我的 Discord 伺服器
看某 server 的頻道列出 Aiworks 團隊小空間 的所有頻道
整理某頻道近期討論整理本週 #channel-name 的討論重點
找特定資訊#channel-name 上次討論到 X 的結論是什麼?
跨頻道補進度整理今天 #channel-A、#channel-B、#channel-C 的重點
看討論串讀取 #channel-name 裡 [thread 名] 那個討論串
看最近有誰 @ 我整理過去 24 小時有人 @ 我的訊息,哪些重要、建議怎麼回

寫入功能

會跳一個確認框,避免誤送

你想做直接這樣打
發訊息發訊息到 #channel-name:今天的會議改到 4 點
回覆某則訊息回覆 [某則訊息]:收到,明天回你
只草擬不送幫我草擬一則回覆放在 #channel-name,內容大概是 ...
不要說「送出」就好

送出的訊息會自動帶署名 footer:

— Sent via Aiworks Discord Agent Requested by: <你的 Discord 名稱> Source: ChatGPT Enterprise

不會偽裝成你本人發。內容含 @everyone / @role 也不會真的觸發通知。

解除連線

需要重置授權時

你想做打
解除 Discord 授權斷開 Discord-MCP 連線

建議使用情境

7 個高頻場景,看著抄

  1. 早上補進度
    整理昨天到今天 #channel-A、#channel-B、#channel-C 我可能要知道的重點
  2. 會後同步
    整理今天 #standup 大家報告的進度,列出 action items
  3. 新人融入第一週
    我是新人,從 #onboarding 跟 #general 幫我整理這週該知道的 5 件事
  4. 追討論結論
    上次 #marketing 討論到 Q3 campaign 的最終決定是什麼?
  5. 草擬訊息
    幫我草擬一則公告要發到 #announcement,提醒大家明天放颱風假
  6. 積壓回覆
    #channel-name 最近有幾則 @我,幫我整理哪些重要、建議怎麼回
  7. 找上下文
    這位同事剛提到 [關鍵字],他指的可能是哪份歷史討論?

限制

先說好,避免誤會

  • ×
    不能讀 DM(私人訊息)
  • ×
    不能搜尋整個 server,要指定頻道
  • ×
    不能看你 Discord 看不到的頻道(這是設計、不是 bug)
  • !
    寫入訊息一定帶署名 footer,無法完全偽裝是你本人發
  • !
    第一次對特定資源動作時 ChatGPT 可能會跳確認框,按確認就好
  • i
    看不到頻道內所有 thread 的清單,要直接點名是哪個 thread 或貼 thread 連結

授權流程

底層怎麼運作 — 給好奇的人看

sequenceDiagram
    participant U as 使用者
    participant C as ChatGPT Connector
    participant M as Discord MCP Server
    participant D as Discord OAuth
    participant A as Discord REST API
    participant DB as Firestore

    U->>C: 連接 Discord MCP
    C->>M: /oauth/authorize<br/>PKCE + client_id
    M->>DB: 建立 pending auth<br/>綁定 workspaceId + state
    M-->>U: Redirect 到 Discord OAuth

    U->>D: 用自己的 Discord 帳號登入並同意授權
    D-->>M: /oauth/callback<br/>code + state

    M->>D: exchange code
    D-->>M: Discord user access token
    M->>D: /users/@me
    D-->>M: discordUserId / username

    M->>DB: bind identity<br/>workspaceId + discordUserId<br/>加密儲存 Discord token
    M-->>C: 回傳 MCP authorization code

    C->>M: /oauth/token<br/>code + PKCE verifier
    M->>DB: 建立 MCP session<br/>workspaceId + discordUserId
    M-->>C: MCP access token<br/>綁定該 Discord user

    C->>M: 呼叫 MCP tool<br/>Bearer MCP access token
    M->>DB: resolve session<br/>還原 workspaceId + discordUserId

    M->>A: 查 guild / channel / member / roles
    A-->>M: Discord 即時權限資料

    M->>M: 計算 user + bot effective permission

    alt user 和 bot 都有權限
        M->>A: 用 bot token 讀取或送出
        A-->>M: 成功
        M-->>C: 回傳結果
    else 任一方沒權限
        M-->>C: permission_denied
    end
